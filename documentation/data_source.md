# Data Source
- **Dataset:** Online Retail (UCI Machine Learning Repository), 541,909 rows, transactions of a UK-based online gift retailer, 1 Dec 2010 to 9 Dec 2011.
- **Download used:** https://www.kaggle.com/datasets/carrie1/ecommerce-data
- **Original source:** https://archive.ics.uci.edu/dataset/352/online+retail
- **Citation:** Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33
- **License:** CC BY 4.0
- **Reuse:** same data as Project 1. This project asks a different question of it (customer retention instead of sales performance).
- **Downloaded:** 10 Oct 2026
- **Columns:** InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country
