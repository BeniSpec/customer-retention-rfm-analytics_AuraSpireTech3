# tableau/

Tableau workbook for this project: `retention_rfm_dashboard.twbx` (packaged workbook — data is bundled in, no separate file links needed to open it).

## Sheets built
1. Retention Curve — cohort retention over time
2. RFM Segments — revenue by customer segment
3. Customer Behaviour Trends — recency vs frequency scatter, by segment

All three are combined into one Overview Dashboard.
